## 🚀 Featured Project

### [sLLMates](https://github.com/HandongSF/sLLMates)
> An agentic chatbot system powered by local LLMs.

- 🧠 **Agentic problem solving**: The LLM plans how to approach a query and decides when to use tools.
- ⚡ **Response optimization**: Controls the LLM's Thinking Mode based on query difficulty to improve response speed.
- 💾 **Personalized memory**: Extracts and stores user-specific information from conversations to improve future answers.
- 🗂 **Chat management**: Saves conversation history in a database and lets users manage chats by chat room in the UI.
